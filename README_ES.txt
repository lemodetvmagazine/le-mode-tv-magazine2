ACTUALIZAR NOTICIAS MANUALMENTE
1. Abre index.html en un editor de texto o código.
2. Busca `const posts=[`.
3. Sustituye los títulos, descripciones y enlaces de ejemplo por publicaciones reales.
4. Cada elemento tiene cat, title, desc, style, label y url.
5. Guarda y vuelve a publicar la carpeta completa.

PUBLICAR GRATIS COMO SITIO/PWA
1. Crea/inicia sesión en GitHub.
2. Crea un repositorio público, por ejemplo le-mode-tv-magazine.
3. Sube TODOS los archivos de esta carpeta a la raíz del repositorio.
4. En Settings > Pages, selecciona Deploy from a branch, la rama main y / (root); guarda.
5. GitHub mostrará la dirección pública cuando termine el despliegue.
6. En iPhone abre el sitio con Safari > Compartir > Añadir a pantalla de inicio.
7. En Android abre el sitio con Chrome > menú > Instalar aplicación o Añadir a pantalla de inicio.

DOMINIO PROPIO
No cambies el DNS de lemodetvmagazine.online hasta comprobar quién administra el dominio y dónde está alojada la web actual. Si deseas usar GitHub Pages con tu dominio, configúralo en Settings > Pages > Custom domain y sigue los registros DNS que GitHub muestre. Esto podría reemplazar o afectar el sitio actual; considera usar primero un subdominio como app.lemodetvmagazine.online y confirma con tu proveedor antes de modificar DNS.

IMPORTANTE SOBRE LAS TIENDAS
Este paquete es una app web progresiva inicial, NO es todavía un archivo Android AAB/APK ni una app iOS lista para App Store. Publicar en Google Play normalmente requiere registro de desarrollador de US$25 una sola vez. Apple Developer Program cuesta US$99/año para distribución en App Store. Ambas tiendas revisan las aplicaciones; una simple envoltura de web puede no ser aceptada. Se necesitará empaquetado nativo, pruebas, privacidad, fichas de tienda y revisión adicional.

Antes de lanzar públicamente, elimina los textos de ejemplo y añade un correo de contacto y una política de privacidad apropiada. No incluye feed automático de redes sociales ni panel de administración: las publicaciones se editan en index.html.
